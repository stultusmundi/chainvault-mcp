# @chainvault/core

Secure MCP server core for ChainVault MCP: vault-based key management, a
rule-enforced access control engine, EVM chain adapters, and an API proxy —
so AI agents get blockchain superpowers without ever touching a private key.

See the [project README](https://github.com/stultusmundi/chainvault-mcp#readme) for setup, tool reference, and the full security model.
